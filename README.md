# 스피드옥션 경매 물건 × 정비구역 자동 매칭

스피드옥션에서 구별 진행 물건을 자동으로 모아(또는 엑셀로 받아) 각 물건이 정비구역 안에 있는지 판정하고 결과 엑셀을 만듭니다.

```
sa_collect.py (자동 수집)  또는  스피드옥션 '엑셀' 저장(수동)
                              ▼
                         input 폴더
                              ▼
          엑셀 해석 → 브이월드 지오코딩·필지 경계 → 정비구역 폴리곤과 비교
                              ▼
          output\재개발매칭_YYYYMMDD_HHMM.xlsx
          (구역안·걸침 / 경계근접 / 전체 / 좌표실패 시트)
```

## 출처
- **스피드옥션**: 본인 유료 계정으로 로그인해 종합검색 결과를 읽습니다. 이용약관 제20조가 크롤링·스크래핑을 금지하므로 **계정 제한 위험은 사용자가 감수**합니다. 이를 줄이려고 페이지 사이 3~6초, 구 사이 6~10초를 쉬고, 주 1회만 돌리도록 했습니다. 문제가 생기면 수동 엑셀 저장 방식(2장)으로 바꾸면 됩니다.
- **재개발닷컴**: 요청 서명과 응답 암호화로 보호돼 있어 쓰지 않습니다.
- **정비구역 경계**: 공공데이터(국토부·서울시 SHP)를 씁니다.

## 0. 자동 수집 (sa_collect.py)
1. 1장 설정 뒤 브라우저를 설치합니다: `.venv\Scripts\playwright install chromium`
2. `.env.credential`에 `SA_ID`, `SA_PW`를 넣습니다(이 PC에만 저장). 비워 두면 창에서 직접 로그인합니다.
3. 처음 한 번은 창을 보면서 실행: `.venv\Scripts\python sa_collect.py --headed`
   - 로그인 세션은 `state\browser_profile`에 남아 다음부터는 창 없이 돕니다.
4. 이후에는 `run_weekly.bat`을 작업 스케줄러에 **매주 월요일**로 등록합니다. 로그는 `collect.log`에 남습니다.
5. 서울 전체로 넓히려면 `.env.normal`의 `DISTRICTS=`를 비우거나 `sa_collect.py --districts ""`로 실행합니다.

### 관심물건 자동 저장
`sa_collect.py`는 매칭이 끝나면 **구역안·구역걸침** 물건을 스피드옥션 **관심경매물건 > 박태준** 폴더에 저장하고, 메모에 다음 내용을 적습니다.
```
[26.11.19 자동매칭] ○○구역 안 (필지 100% 포함). 구역자료 <파일명>
대지권 3.27평, 최저가 0.16억(11%), 대지 평당 최저가 493만원
특수조건: 재매각, 대항력있는임차인
확인할 것: ① 구역 단계·권리산정기준일 ② 보존등기일 ③ 경매신청 채권자 ④ 같은 구역 낙찰가율
```
- **이미 관심물건에 있는 물건은 건너뜁니다.** 기존 폴더와 메모를 덮어쓰지 않으려는 것이고, 결과는 `output\관심저장_*.csv`에 남습니다.
- 폴더, 판정 범위, 중요도는 `.env.normal`의 `INTEREST_FOLDER`, `INTEREST_JUDGES`, `INTEREST_STAR`로 바꿉니다. 저장하지 않으려면 `SAVE_INTEREST=0`으로 두거나 `--no-interest`를 붙입니다.
- 결과 엑셀만으로 따로 저장하려면 `python sa_interest.py`를 실행합니다. 저장 전에 메모를 미리 보려면 `--dry-run`을 붙입니다.

수집 방식: 종합검색 화면에서 소재지(서울/구)를 고른 뒤, 화면이 쓰는 검색 요청(`search@auction_result.ajax`)을 150건씩 보내 결과표를 읽습니다. 매각기일 범위는 화면 기본값(오늘~3개월)입니다. 2026-11-19 기준 관악구는 340건으로 3쪽이었습니다.

## 1. 처음 한 번 설정

1. Python 3.10 이상 설치 후 이 폴더에서:
   ```
   python -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   ```
2. **브이월드 인증키** 발급: vworld.kr 회원가입 → 오픈API → 인증키 발급(무료). 활용 API에서 **Geocoder API**(주소→좌표)와 **2D데이터 API**(연속지적도 필지 경계) 두 개를 고릅니다. 하나의 키로 둘 다 씁니다.
3. `.env.credential.example`을 `.env.credential`로 복사해 `VWORLD_KEY`(와 `SA_ID`, `SA_PW`)를 채웁니다. 일반 설정은 `.env.normal`에 있습니다(`WORK_DIR` 등).
4. **정비구역 파일**을 `WORK_DIR\zones`에 넣습니다. 압축을 풀어 .shp, .shx, .dbf, .prj를 모두 넣으세요.
   - 국토교통부_(연속주제)_도시및주거환경정비_정비구역 (공공데이터포털, 파일데이터 SHP)
   - 서울 열린데이터광장 "의제처리구역" SHP: 재정비촉진지구 등 포함
   - (선택) 신통·모아타운 **후보지**는 위 자료에 없을 수 있습니다. geojson.io에서 경계를 그려 속성에 `name`(예: "중곡동 신통 후보지")을 넣고 `.geojson`으로 저장해 같은 폴더에 넣으면 함께 매칭됩니다.
   - 구역 파일은 한 달에 한 번 정도 새로 받아 교체하세요.

## 2. 수동 방식: 엑셀 저장 (자동 수집을 쓰지 않을 때, 약 1분)

1. 스피드옥션 → 경매검색 → 종합검색 → 소재지 **서울 / 광진구** → 검색하기
2. 목록을 **150개씩 보기**로 바꾸고 **엑셀** 버튼을 누릅니다. 결과가 150건을 넘으면 페이지마다 반복합니다. 엑셀 저장은 화면에 보이는 표만 내보냅니다.
3. 관악구도 같은 방법으로 받습니다.
4. 받은 파일을 `WORK_DIR\input`으로 옮깁니다.
   - Chrome 다운로드 폴더(`경매서류_claude`)를 그대로 input으로 지정하지 마세요. 그 폴더의 다른 엑셀까지 처리 대상이 됩니다.

`--watch`가 켜져 있으면 파일이 들어온 뒤 1분 안에 결과가 `output`에 생깁니다.

## 3. 실행
```
.venv\Scripts\python match_auctions.py --dry-run   # 처음 한 번: 엑셀을 제대로 읽는지만 확인 (인증키 불필요)
.venv\Scripts\python match_auctions.py             # 지금 input에 있는 파일을 처리
.venv\Scripts\python match_auctions.py --watch     # 폴더를 지켜보며 자동 처리
.venv\Scripts\python match_auctions.py --districts ""   # 서울 전체 (구 필터 해제)
```
**PC를 켤 때마다 자동으로 실행하려면**: 작업 스케줄러 → 기본 작업 만들기 → 트리거 "로그온할 때" → 동작 "프로그램 시작" → `run_watch.bat`. 로그는 `watch.log`에 남습니다.

## 4. 결과 읽는 법

| 열 | 뜻 |
|---|---|
| 판정 | **구역안**(필지의 50% 이상이 구역 안), **구역걸침**(일부만), **경계근접**(구역 밖 50m 이내), 해당없음, 좌표실패 |
| 입주권단계 | 구역안·걸침 물건의 사업 단계 구간. **A** 정비구역지정~사업시행인가(조합원 승계 제한 없음), **B** 분양신청(낙찰 시점·분양신청 기간 확인), **C** 관리처분인가 후(금융기관·국가 채권자 경매만 승계), **제외**(후보지·이주 이후), **재건축**(양도 제한 시점이 달라 별도 확인), **재개발외**(소규모주택정비·가로주택·주거환경개선 등), **단계미확인**(재개발 계열인데 단계 자료가 없음). 서울=투기과열지구 가정의 작업용 기준이며 입찰 전 법령·조합 확인 필요 |
| 사업단계, 단계확인일 | `zone_stage.csv`에서 읽은 구역별 단계 |
| 겹침% | 필지 면적 중 구역 안 비율 (`USE_PARCEL_POLYGON=1`일 때) |
| 구역명, 구역속성 | 구역 파일의 이름과 속성 전체 (단계·고시일이 있으면 여기에 나옴) |
| 대지평당최저가(만원) | 최저가 ÷ 대지권(평). 같은 구역 안 물건 비교용 |
| 신규 | 이전 실행에서 본 적 없는 물건 |
| 확인할것 | 구역 관련 물건에 붙는 지침 9항 체크 항목 |
| 상세링크 | 스피드옥션 상세페이지 (로그인 필요) |

## 4-1. 사업 단계 자료 (zone_stage.csv)
구역 SHP에는 정비구역 지정 고시일만 있고 조합설립·사업시행·관리처분 인가 같은 **진행 단계가 없습니다.** 단계는 `WORK_DIR\zone_stage.csv`(열: 구역키워드, 단계, 확인일, 출처, 비고)에 직접 채웁니다.
- 틀 만들기: `python stage.py --template` (최신 결과 엑셀의 구역을 키워드로 추가, 기존 행은 유지)
- 단계 값: 후보지, 정비구역지정, 추진위원회, 조합설립인가, 사업시행인가, 분양신청, 관리처분인가, 이주, 철거, 착공, 준공, 이전고시. 구역키워드 뒤에 숫자가 이어지면 다른 구역으로 봅니다(신림1 ≠ 신림10).
- 결과 엑셀의 `입주권가능` 시트는 구역안·걸침 중 A/B/C만 모은 것입니다. 관심물건 저장 범위는 `.env.normal`의 `INTEREST_STAGES`(기본 `A,B,C,단계미확인`)로 정하며, 단계 자료를 채운 뒤에는 `단계미확인`을 빼세요.
- 구역 목록에는 재개발 외 유형(가로주택·주거환경개선 등)도 섞여 있습니다. 입주권 기준은 재개발 기준이므로 다른 유형은 별도로 확인하세요.

### 서울시 추진현황 가져오기
서울 열린데이터광장의 「서울시 정비사업 추진현황」 xlsx(분기 자료, 법적 효력 없음)를 `WORK_DIR`에 두고 `python stage_seoul.py`를 실행하면 `.env.normal`의 `DISTRICTS` 구만 `zone_stage.csv`로 가져옵니다. 자료 기준일은 `--asof 2026-06-30`처럼 지정합니다. 구역명은 `신림5구역주택재개발사업` → `신림5`처럼 줄여 매칭하고 자치구가 같을 때만 씁니다. 사업시행인가 후 120일이 지난 구역은 분양신청 시기로 **추정**해 B로 둡니다(`SALE_NOTICE_DAYS`). 같은 구역에 더 최근 확인일의 행(구청 고시, 수동 입력)이 있으면 그 값이 쓰입니다.

### 구청 고시로 최신화 (stage_notice.py)
서울시 자료는 분기 자료라 최대 몇 달 늦고 분양신청 단계가 없습니다. `python stage_notice.py`는 대상 구 구청 홈페이지의 **고시공고 게시판**에서 정비사업 고시를 읽어 `zone_stage.csv`에 행을 더합니다. `run_weekly.bat`이 매주 `sa_collect.py`보다 먼저 실행합니다(로그 `collect.log`).
- **지원하는 구**: 관악구, 광진구. 구청마다 게시판 형식이 달라 구별 어댑터(`GwanakAdapter`, `GwangjinAdapter`)로 나눴습니다. `DISTRICTS`에 어댑터가 없는 구가 있으면 건너뛰고 알려 줍니다.
- **읽는 방법**: 제목 검색어 `정비, 재개발, 재건축, 분양`으로 게시판을 검색해 키워드별 1쪽(관악 30건, 광진 10건)을 읽습니다. 처음 한 번은 `--pages 3`으로 예전 고시까지 채우세요. 대상 고시는 상세 페이지도 읽어 **권리산정기준일**이 있으면 비고에 적습니다.
- **고르는 고시**: 공고번호가 '고시'인 것 중 조합설립·추진위원회·사업시행·관리처분·정비구역 지정·준공·이전고시. '공고'는 **분양신청 공고**만 씁니다. 공람·열람·설명회·선거·공시송달·재결·용역 공고와, 단계가 바뀌지 않는 정비계획 경미한 변경은 건너뜁니다.
- **단계 해석**: `stage.normalize_stage(제목)`. 해석이 안 되거나 여러 단계가 섞이면 건너뛰고 로그에 남깁니다. 변경 고시(예: 관리처분계획 변경인가)는 같은 단계로 두고 비고에 `변경`을 적습니다. **취소·폐지·해산·실효·해제** 고시는 단계를 올리지 않고 `확인필요`로 로그에 남깁니다.
- **구역키워드**: 제목에서 사업 종류 앞부분을 구역명으로 보고 `stage_seoul.keyword_of`로 줄입니다. 서울시 자료 표기에 맞춰 `봉천제4-1-3` → `봉천4-1-3`처럼 '제'를 뺍니다.
- **병합 규칙**: 확인일 = 고시일(관악구 고시는 공고일자가 비어 있어 등록일), 출처 = `관악구 고시 제2026-63호`, 비고에 원 제목과 URL. 병합 키는 (자치구, 구역키워드, 출처)라 서울시 자료 행과 사람이 적은 행은 그대로 남고, `stage.lookup`이 확인일이 가장 늦은 고시 행을 씁니다. 같은 구역에 **이미 더 높은 단계가 기록돼 있으면 쓰지 않습니다**(착공한 구역에 사업시행계획 변경인가가 나와 단계가 되돌아가는 것을 막음).
- **요청 간격**: 관악구 3~6초, 광진구 10~13초(robots.txt `Crawl-delay: 10`), 구 사이 6~10초, 병렬 요청 없음. 로그인하지 않는 공개 페이지만 읽습니다.
- **출처 정찰 결과(2026-11-20)**: 관악구 robots.txt는 Googlebot에만 옛 게시판 경로를 막고 이 게시판은 막지 않습니다. 광진구는 이 게시판(`B0000378`)을 Allow하고, 2025년 9월 이전 고시판(`B0000003`)은 허용하지 않아 읽지 않습니다. 토지이음 고시정보는 지형도면이 붙는 고시만 있어(조합설립·사업시행·관리처분 인가 없음) 쓰지 않습니다. 두 구청 모두 공공누리 기준(출처 표시)이며 자동 수집 금지 조항은 없습니다.
- 네트워크 없이 다시 해석하려면 브라우저로 저장한 게시판 묶음을 `python stage_notice.py --from-json 묶음.json`으로 넣습니다. 결과는 참고용이고 법적 효력은 구 고시 원문에 있습니다.

## 5. 한계와 주의
- 공공 SHP는 **참고자료**이고 법적 효력이 없습니다. 최종 판단은 토지이음·정비사업 정보몽땅·구청에서 확인하세요.
- **후보지 단계**(신통·모아타운 선정 전후)는 공공 SHP에 빠져 있을 수 있습니다. 직접 그린 GeoJSON으로 보완하세요.
- 권리산정기준일·조합원 지위·분양자격은 이 프로그램이 판단하지 않습니다. `확인할것` 열을 보고 물건별로 확인하세요.
- 스피드옥션 엑셀 형식이 바뀌면 `speedauction_excel.py`의 해석 규칙을 고쳐야 합니다. 먼저 `--dry-run`으로 확인하세요.
- 국토부 정비구역 SHP의 이용허락은 공공누리 제4유형(출처표시, 상업적 이용금지, 변경금지)입니다. 개인 분석용으로만 쓰세요.

## 파일 구성
| 파일 | 역할 |
|---|---|
| sa_collect.py | 스피드옥션 로그인·구별 수집 → input 저장 → 매칭 실행 |
| sa_interest.py | 매칭 물건을 관심경매물건 폴더에 메모와 함께 저장 |
| stage_notice.py | 구청 고시로 zone_stage.csv 사업 단계 최신화 (관악구·광진구) |
| run_weekly.bat | 작업 스케줄러용 (구청 고시 → 수집 + 매칭 + 관심물건 저장) |
| match_auctions.py | 매칭 진입점: 읽기 → 지오코딩 → 매칭 → 엑셀 저장, `--watch` |
| speedauction_excel.py | 스피드옥션 엑셀(HTML 표 형식 포함) 해석, 상세링크 생성 |
| geocode.py | 브이월드 지오코더·연속지적도, 결과 캐시 |
| zones.py | 정비구역 SHP/GeoJSON 읽기, 서울 범위 필터, 좌표계 통일 |
